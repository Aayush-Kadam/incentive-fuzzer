# Incentive Fuzzer External Review Package

This package is for independent economists, policy-domain specialists, and formal-methods reviewers. It does not claim that internal hostile review substitutes for external review.

Start with `EXTERNAL_CASES_SUMMARY.md`, then inspect the relevant card under `cases/`, the cited source, the runtime encoding, and `REVIEW_FORM.md`. Reviewers may assess only cases within their expertise and should disclose conflicts and the depth of source checking performed.

The frozen M7 findings and labels must not be edited in place. Proposed corrections should be recorded in a completed review form and handled as versioned follow-up evidence.
