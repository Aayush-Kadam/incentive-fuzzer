# Encoding Review Guide

Verify source date, jurisdiction, units, comparison inclusivity, threshold or rate values, schedule continuity, and arithmetic independently. Then inspect `case.yaml`, `ENCODING_NOTES.md`, and—where formalized—the generated IncentiveSpec.

All M7 external encodings are scalar components. They omit substantial eligibility, administrative, valuation, and behavioral detail. A correct scalar threshold does not establish program-level fidelity. The Arizona proxy is the strongest warning: official transition thresholds did not justify additive cash coverage values, so the project preserved a miss instead of forcing a pathology.
