# Robustness Protocol

The frozen M4 design is in `research/M4_PRECOMMITMENT.md`. Deterministic grids cross boundary states with fixed frictions and, for the scholarship fixture, action-cost multipliers. The raw cell table preserves every state/cost/scenario result. The break-even table reports both the exact weak threshold at which strict profitability disappears and the first value present in the tested grid.

Search error is the signed difference `B1 profitable share - B0 profitable share`. Scenario robustness is reported through both opportunity prevalence and actual response because B2 can observe but decline a profitable action. Monte Carlo draws use a local RNG, seed 20260926, and frozen sample sizes; Wilson intervals describe binomial sampling uncertainty only.

The scholarship holdout (500006–500010) was not used to select ranges or scenarios. It is an implementation holdout, not empirical external validation.
