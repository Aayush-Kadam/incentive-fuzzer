# Parameter Provenance

Codes are: **E** empirical, **L** literature-derived, **S** synthetic, and **A** assumption/sensitivity. Every population parameter may carry a source and rationale.

All M4 fixture states, weights, thresholds, awards, and sampled type probabilities are synthetic (**S**). Fixed frictions, cost multipliers, the B1 search limit, and B2 hurdle are sensitivity assumptions (**A**). No M4 parameter is labeled empirical or literature-calibrated. The engine stores these codes on types; the experiment precommitment and manifest document scenario-level assumptions.
